GameVault login password → hash

Type the password you want to log in with. This page turns it into the one-way hash that goes into GAMEVAULT_PASSWORD_HASH. Everything runs on your phone — nothing is sent anywhere, and it works offline.

—
Format: pbkdf2$sha256$600000$salt$hash
Paste the hash only into Render → your service → Environment → GAMEVAULT_PASSWORD_HASH. Never paste your password into Render, chat, or Git, and never commit this hash. Keep the password itself in a password manager.
