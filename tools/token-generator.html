GameVault access token

This makes a random 64-character secret for GAMEVAULT_AUTH_TOKEN. It is generated on your phone — nothing is sent anywhere, and it works offline.

tap “Generate”
Keep it secret. Use the same value in two places: the server environment variable GAMEVAULT_AUTH_TOKEN, and the “Access token” box that GameVault shows when you open the site. Store it in your password manager — if you lose it you can just generate a new one and update the host variable. Do not put it in Git or send it to anyone.
